Proje Adı: MyPortfolioUdemy

Bu proje, ASP.NET Core 6.0 ile geliştirilmiş bir API uygulamasıdır. Projede Entity Framework Core ve SQL Server kullanılarak veri tabanı işlemleri yapılmaktadır.

## Proje Özellikleri
- ASP.NET Core 6.0 kullanarak API geliştirme.
- Entity Framework Core ve SQL Server ile veri tabanı işlemleri.
- Code First yaklaşımıyla veri modellemesi.
- LINQ sorguları ile veriye erişim ve manipülasyon.
- Model-View-Controller (MVC) tasarım deseni kullanılarak uygulama geliştirilmesi.
- Migration işlemleriyle veri tabanı güncellemeleri.
- HTML, CSS, ve Bootstrap ile kullanıcı arayüzü.
- JavaScript

Kullanılan Teknolojiler
-ASP.NET Core 8.0
-Entity Framework Core
-Microsoft.EntityFrameworkCore (Tools, Design, SQL Server)
-Code First Yaklaşımı
-LINQ Sorguları
-Model-View-Controller (MVC)
-HTML, CSS, Bootstrap
-JavaScript
-SQL

Proje Hedefleri
Kullanıcı ekleme, güncelleme, silme işlemleri.

Basit bir CRUD uygulaması oluşturmak.

Veritabanı ile dinamik olarak çalışmak.
